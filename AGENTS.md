## Agent skills

### Issue tracker

Issues live in GitHub Issues for NGL321/patchworks, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Registers

**Before implementing anything, or exploring a space of solutions, read `docs/registers/`** — what is
known to be wrong, what has been proposed, and what has been excluded. Report what you found on the
`Registers consulted:` line of your PR or issue comment. See `docs/agents/registers.md`.
